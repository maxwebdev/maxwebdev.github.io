# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Проект

Astro 6, статический сайт ювелирной мастерской «Артель» (Санкт-Петербург). Весь пользовательский контент — на русском; слаги URL — транслитерация кириллицы (например, `umenshenie-kolecz`, `obruchalnye-kolca-na-zakaz`). В корне репозитория лежит только workflow деплоя и конфиги — **весь код приложения находится в `site/`**, и все npm-команды запускаются оттуда.

Требуется Node `>=22.12.0`.

## Команды

Выполнять из `site/`:

```sh
npm install              # установить зависимости
npm run dev              # дев-сервер на localhost:4321
npm run build            # сборка в site/dist/
npm run preview          # предпросмотр прод-сборки
npm run astro -- <cmd>   # например: astro check, astro add
```

Тестов, линтера и форматтера в проекте нет.

## Деплой

`.github/workflows/deploy.yml` собирает `site/` при пуше в `main` и публикует `site/dist` на GitHub Pages. В `astro.config.mjs` задано `site: 'https://maxwebdev.github.io'`. Если Pages-адрес когда-нибудь переедет на подпуть (например, `/jewelrymaster2026/`), в `astro.config.mjs` нужно будет добавить `base` — иначе все абсолютные ссылки `/icons/...` и `/images/...` сломаются.

## Архитектура

### Структура страниц
Три лейаута в `site/src/layouts/`:

- **`Layout.astro`** — базовая HTML-обёртка. Подключает `styles/global.css` (дизайн-токены), грузит Cormorant Garamond + Jost с Google Fonts, отдаёт слот `head`.
- **`InnerPage.astro`** — оборачивает `Layout` для сервисных/внутренних страниц. Рендерит `HeaderDropdown`, хлебные крошки, sticky-сайдбар (на мобильных сворачивается в `<details>`-аккордеон), слот основного контента, фиксированную мобильную CTA-плашку (звонок / WhatsApp на `+79319616090`) и `Footer`. Принимает пропсы `crumbs`, `sidebarLinks`, `sidebarTitle`, `activeHref`. **Большинство сервисных страниц используют именно его.**
- **`PlaceholderPage.astro`** — заглушка «В разработке», используется для ещё не свёрстанных страниц (в том числе `pages/index.astro`).

### Компоненты = блоки лендинга
`site/src/components/` следует паттерну «один файл = один блок». `pages/design-system.astro` рендерит все блоки подряд и служит каноничной площадкой предпросмотра — при изменении или добавлении блока смотри его именно там. Стили компонента живут в его собственном `<style>` (без `is:global`, если только не нужно перебить scope лейаута).

### Дизайн-система
`site/design-code/CONTEXT.md` — авторитетный справочник по токенам, маппингу компонент → CSS-класс, брейкпойнтам, анимациям и визуальному языку. **Читай его, прежде чем верстать новые блоки или страницы.** Сами токены лежат CSS-переменными в `site/src/styles/global.css` — никогда не хардкоди фирменные цвета, отступы и размеры шрифтов; пользуйся переменными `--color-gold-*`, `--spacing-*`, `--font-size-*`. Брейкпойнты: 1024px (планшет), 760px (большой мобильный), 500px (мобильный).

Паттерн аккордеона использует `grid-template-rows: 0fr → 1fr` с асимметричным таймингом открытия/закрытия (0.42s spring out / 0.22s ease-in) — см. `FAQ.astro`. Не использовать `<details>` для анимированного контента: скоростью закрытия управлять нельзя.

### Интеграция с Sanity CMS
Прайс-таблицы тянутся из Sanity на сборке через `site/src/lib/sanity.ts` (проект `5byn3t53`, датасет `production`, `useCdn: true`). `SanityPriceTable.astro` запрашивает таблицу по slug и подтягивает глобальный `usdRate` из синглтона `siteSettings` — цены хранятся в центах USD и пересчитываются в рубли с округлением до 100 ₽. Чтобы добавить таблицу на страницу: `<SanityPriceTable slug="..." />`. Схемы Sanity (`priceTable`, `siteSettings`) живут в отдельном проекте Sanity Studio, не в этом репо.

### Соглашение по внутренним страницам
В каждом сервисном разделе (`pages/repair/`, `pages/manufacturing/`, `pages/engraving/`, `pages/watch-repair/`) массив сайдбар-ссылок дублируется в начале каждой страницы. При добавлении нового сервиса нужно добавить запись в `repairLinks` (или аналог) **во всех соседних страницах** — общего источника правды нет. Массивы `crumbs` устроены так же. Слаги в URL — транслитерация кириллицы; при создании новых страниц соблюдай существующий стиль.
